# Dalsze działania — niezależnie od MultiFX

Repozytorium `JerzyRPiAudioLab` zostało założone i otrzymało katalog projektów. W tym repo zapisujemy instrukcje i konfigurację eksperymentów, a nie cudze kod źródłowe bez poszanowania licencji.

1. Przygotować osobne karty microSD; oznaczyć numerem i projektem.
2. Bez naruszania karty 00 wykonać eksperyment CARD-01 PiPedal i potwierdzić HeadRush Core.
3. Potem CARD-02 Zynthian, następnie CARD-03 Patchbox/MODEP.
4. W tym repo zapisywać dla każdej karty wersję projektu, obraz, sumy SHA256, konfigurację i wyniki.

Uwaga: te kroki są planem, żaden obraz karty nie został wygenerowany. Nie flashować karty 00.
