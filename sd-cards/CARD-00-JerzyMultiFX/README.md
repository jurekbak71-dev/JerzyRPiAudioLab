**NIE NADPISYWAĆ.** Karta Raspberry Pi OS Lite x64 ARM64, JACK2, HeadRush Core USB, hotspot `Jerzy-MultiFX`.

- Zweryfikowana fizycznie: MultiFX v0.2, panel http://10.42.0.1:8090/, potwierdzony autostart po restarcie RPi z HeadRush Core.
- Nowa funkcjonalność jest opracowana jako MultiFX v0.4 na osobnej gałęzi (do testów): [docs/MULTIFX4.md](../../docs/MULTIFX4.md).
- Kod można klonować przez [projects/JerzyMultiFX](../../projects/JerzyMultiFX) jako submodule; nic nie zostało zmienione na prawdziwej karcie SD.

Testuj nowe wersje wyłącznie na sklonowanej lub osobnej karcie microSD.
