# CARD-04 — CamillaDSP: profesjonalne DSP / konwolucja / routingi

Źródło: https://www.camilladsp.com/

CamillaDSP umożliwia korekcję FIR, IR, zwrotnice aktywne, EQ, matrycę wejść/wyjść i konfigurację przez CamillaGUI. Można użyć do testowania IR i DSP, ale nie jest to gotowy pedalboard gitarowy z symulacjami wzmacniaczy.

## Typ karty
Raspberry Pi OS + silnik CamillaDSP + CamillaGUI, instalacja według oficjalnej dokumentacji.

## Do zweryfikowania
Obsługa wejścia z HeadRush, metoda routingu ALSA/JACK, latencja konwolucji, maksymalny rozmiar IR, oddzielny hotspot.
