# CARD-02 — Zynthian: syntezatory, pady, sampler, looper

Źródła: https://zynthian.org/ i https://wiki.zynthian.org/index.php/No_Hardware_Build

## Co jest ciekawe
Wiele silników instrumentów; synteza, sample/SF2, sekwencer, efekty LV2, zapis zestawów, kontrola MIDI. Świetne do ambientu i akompaniamentu.

## Typ karty
Dedykowany obraz ZynthianOS na oddzielnej microSD. Tryb bez obudowy (No Hardware Build) udokumentowany dla Pi 4.

## Do zweryfikowania
Konfiguracja custom hardware; ALSA/JACK dla HeadRush Core; dostęp z iPada do webconf lub VNC; obsługa hotspotu; ograniczenie CPU przy kilku syntezatorach.

## Wynik testu
Jeszcze nie instalowano.
