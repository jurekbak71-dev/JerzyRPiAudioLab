# CARD-06 — Pure Data / SuperCollider: generatywna muzyka

Źródła: https://puredata.info/ oraz https://supercollider.github.io/

## Co jest ciekawe
- Krell, drony, generatywne frazy, proceduralne instrumenty i audio-reactive patches.
- MIDI/OSC, DSP w czasie rzeczywistym, synteza własnych instrumentów i efektów.
- Możliwość sterowania parametrami z webowego panelu lub OSC na iPhonie.

## Typ karty
Raspberry Pi OS (zwykle Desktop ułatwia eksperymentowanie), alternatywnie Patchbox OS (uwaga na wiek obrazu). Konfiguracja HeadRush wymaga testu.

## Pomysły
- Krell Generator — bez klawiatury i MIDI.
- Post-punk Bass Accompanist — automatyczny bas + pady w zadanej tonacji.
- Infinite Ambient — pad z wolną ewolucją i probabilistyką.
- Lo-Fi Mechanic — generowanie artefaktów mechanicznych, synchronizowanych z tempem.
