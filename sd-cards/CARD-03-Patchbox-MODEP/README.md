# CARD-03 — Patchbox OS / MODEP / Orac

Źródła: https://blokas.io/patchbox-os/ i https://blokas.io/patchbox-os/docs/ oraz https://github.com/TheTechnobear/Orac

## Co jest ciekawe
- MODEP: modularne efekty (pedalboard) i sterowanie z przeglądarki.
- Orac: generatywny / modularny syntezator z łańcuchami modułów.
- Pure Data, SuperCollider, JACK, MIDI i hotspot.

## Typ karty
Dedykowany obraz Patchbox OS na osobnej microSD. W zależności od celu przełączyć moduł MODEP, Orac lub Pure Data (jeśli dostępny w zainstalowanej wersji).

## Ryzyko
Oficjalna strona podaje obraz z 2022 r. i starsze pakiety audio. Przed podłączeniem do internetu sprawdzić aktualne źródła, obraz i bezpieczeństwo; być może konieczne zbudowanie wersji pod nowszy Raspberry Pi OS.

## HeadRush Core
Patchbox obsługuje także karty USB, lecz konkretna konfiguracja HeadRush nie była testowana.
